# 🎬 ترجمه زیرنویس انیمه

نرمافزار وب برای ترجمه خودکار فایلهای زیرنویس انیمه از انگلیسی به فارسی با استفاده از هوش مصنوعی.

🌐 **نسخه آنلاین:** https://mar-mir.github.io/anime-translator/ — بدون نصب، مستقیم در مرورگر (کلید API فقط در مرورگر شما میماند)

![Python](https://img.shields.io/badge/python-3.8+-blue)
![Flask](https://img.shields.io/badge/flask-web-green)

## ✨ امکانات

- 📁 **آپلود آسان** — فایل SRT یا ASS/SSA رو drag & drop کنید
- 📝 **پشتیبانی SSA/ASS** — فقط متن Dialogue ترجمه میشه؛ تایمینگ، استایلها و تگها (`{\pos(...)}` و ...) دستنخورده میمونن
- 🇬🇧🇮🇷 **نمایش دو ستونه** — متن اصلی و ترجمه فارسی کنار هم
- 🌙 **حالت شب** — تم تیره چشمنواز با فونت نارنجی
- 🤖 **ترجمه هوشمند** — بچینگ با بافت برای کیفیت بهتر
- 🔑 **کلیدهای API متعدد** — پشتیبانی از چند مدل مختلف
- ✏️ **ویرایش دستی** — ترجمهها رو بعد از ترجمه اصلاح کنید
- 📥 **خروجی همفرمت ورودی** — `*_fa.srt` یا `*_fa.ass` رو دانلود کنید
- 📊 **پیشرفت لحظهای** — نوار پیشرفت و آمار زنده

## 🚀 نصب و اجرا

### پیشنیازها
- Python 3.8+
- کلید API (OpenAI یا سازگار)

### نصب

```bash
# کلون کردن ریپو
git clone https://github.com/Mar-mir/anime-translator.git
cd anime-translator

# نصب وابستگیها
pip install -r requirements.txt

# اجرای برنامه
python3 app.py
```

### دسترسی

بعد از اجرا، مرورگر رو باز کنید:
- **لوکال:** http://localhost:5001
- **از موبایل:** http://[IP_کامپیوتر]:5001

## ⚙️ تنظیمات

### ۱. افزودن کلید API

1. به تب **⚙️ تنظیمات** برید
2. کلید API خودتون رو وارد کنید
3. روی **افزودن** کلیک کنید

### ۲. تنظیم مدل

| تنظیم | پیشفرض | توضیح |
|---|---|---|
| Base URL | `https://api.openai.com/v1` | آدرس API |
| مدل | `gpt-4o-mini` | مدل ترجمه |
| Batch Size | `20` | تعداد خط در هر درخواست |

### ۳. پشتیبانی از مدلهای مختلف

- **OpenAI:** GPT-4o-mini, GPT-4o
- **سازگار:** هر API سازگار با OpenAI (Mistral, etc.)

## 📝 فرمتها

### SRT

فایل زیرنویس شما باید فرمت SRT داشته باشد:

```srt
1
00:00:01,000 --> 00:00:03,500
Hello, how are you?

2
00:00:04,000 --> 00:00:06,500
I'm doing fine, thanks.
```

### SSA/ASS

فایلهای `.ass` و `.ssa` هم پشتیبانی میشن. فقط ستون `Text` خطوط
`Dialogue` ترجمه میشه — `Start`/`End`، استایل، لایه و هدرها
(`[Script Info]`، `[V4+ Styles]`) عیناً حفظ میشن و تگهای اول خط
مثل `{\pos(400,570)}` سر جاشون برمیگردن.

## 💡 نکات

- **ترجمه دستهای:** برای کیفیت بهتر، متنها دستهای ترجمه میشن (با در نظر گرفتن بافت)
- **ویرایش دستی:** بعد از ترجمه، میتونید هر خط رو اصلاح کنید
- **کشینگ:** جملات تکراری دوباره ترجمه نمیشن
- **خروجی:** فایل خروجی با پسوند `_fa` و همون فرمت ورودی ذخیره میشه
- **زمانبندی SSA:** تایمینگ بههم نمیخوره چون فقط متن جایگزین میشه
